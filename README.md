# Odyssey

Ingyenes, magyar nyelvű Minecraft: Java Edition launcher Windowsra, Linuxra és macOS-re.

**[A legfrissebb kiadás letöltése](https://github.com/Aizader/odyssey-launcher/releases/latest)**

## Melyik telepítő kell?

| Rendszer | Fájl |
| --- | --- |
| Windows 64 bites | `Odyssey-…-win-x64.exe` |
| macOS, Apple Silicon (M1 és újabb) | `Odyssey-…-mac-arm64.dmg` |
| macOS, Intel | `Odyssey-…-mac-x64.dmg` |
| Linux, x64 | `Odyssey-…-linux-x86_64.AppImage` vagy `Odyssey-…-linux-amd64.deb` |
| Linux, ARM64 | `Odyssey-…-linux-arm64.AppImage` vagy `.deb` |

A kiadás `SHA256SUMS.txt` fájlja tartalmazza a letöltések ellenőrzőösszegeit.

## Frissítések

A 0.5.0-tól a launcher induláskor ellenőrzi az új kiadásokat. Windows és Linux AppImage esetén automatikusan letölti a frissítést, majd jelzi, amikor telepíthető. A DEB-csomag a rendszer csomagkezelőjével frissíthető.

macOS-en jelenleg nincs Apple Developer ID aláírás és notarizálás. Az Odyssey értesít az új verzióról, és megnyitja a letöltési oldalt; a DMG-ből kézzel kell lecserélni az alkalmazást. Automatikus macOS-telepítés egyelőre nincs.

A 0.4.1-es és régebbi launchert egyszer kézzel kell új kiadásra cserélni. A profilok, világok és Minecraft-telepítések külön felhasználói adatmappában maradnak.

## Fiókok és segítség

Az [Odyssey weboldalán](https://odyssey-community-720614564864.europe-west3.run.app) létrehozott közösségi fiók a launcherben is használható. A Microsoft-fiókos játékhoz külön, megfelelően konfigurált Microsoft/Minecraft-hitelesítés szükséges. Az offline profil nem biztosít hozzáférést Microsoft-hitelesítést igénylő szerverekhez.

Ez a tárhely a nyilvános telepítők és frissítési fájlok helye. A launcher forráskódját külön privát tárhely kezeli. A GitHub „Source code” archívumai csak ennek a nyilvános tárhelynek a leírását tartalmazzák.

Az Odyssey nem hivatalos Minecraft-termék; a Mojang és a Microsoft nem támogatja. A Minecraft használatához szükséges jogokat a launcher nem helyettesíti.
